## Qu'est-ce que MimiLog ?

**MimiLog** est un journal bébé totalement hors ligne et gratuit pour Android et iPhone, conçu pour les parents et personnes en charge d'enfants de la naissance à 3 ans. Il enregistre les tétées, les siestes, les changements de couche, les séances de tire-lait, les mesures de croissance (poids, taille, périmètre crânien) sur les courbes de percentile de l'OMS, et les températures détaillées. Tout est stocké dans une base SQLite locale sur le téléphone — sans compte, sans cloud, sans publicité, sans achats intégrés et sans abonnement. Jamais.

Pensé pour ces moments à 3 h du matin où la dernière chose dont on a besoin est un mur payant.

## Fonctionnalités principales

### Tétée
- **Minuteur d'allaitement** qui se souvient du sein de départ
- **Biberon** en millilitres — lait maternel, lait artificiel, mixte
- **Solides** — texte libre
- **Détection automatique des tétées de nuit** entre 22h et 6h

### Sommeil
- **Sieste & nuit** en un toucher
- **Planning adaptable** du nouveau-né au tout-petit
- **Sommeil jour, nuit et prochaine fenêtre** sur un seul écran

### Couche
- Pipi, caca ou les deux — un toucher
- **Compteur quotidien** avec rappel si le nombre de couches mouillées d'un nouveau-né est trop bas

### Tire-lait
- Gauche, droit ou les deux
- Volume, durée et débit par minute

### Croissance et santé
- **Poids, taille et périmètre crânien** sur les **courbes OMS** intégrées, gratuit
- **Journal de température** avec classification de fièvre en sept niveaux et courbe de tendance
- Bain, visites pédiatre, notes libres

### Famille
- **Plusieurs bébés** — jumeaux, fratrie, données séparées
- **Minuteur partagé** qui survit à un redémarrage
- **Statistiques** par jour, semaine, mois

### Export
- **CSV, Excel ou JSON** directement dans le gestionnaire de fichiers

### Confidentialité
- **100 % sur l'appareil** — base SQLite locale
- **Aucun analytics, aucun ID publicitaire, aucun SDK tiers**
- **Pas d'inscription, ni e-mail ni mot de passe**
- **Mode sombre** pour les tétées de nuit
- **Une main** — boutons larges

## Cas d'usage

| Scénario | Ce que fait MimiLog |
|----------|---------------------|
| Tétée de nuit | Le minuteur retient le sein, marque comme nuit |
| Biberon à la crèche | ml en un toucher |
| Premiers solides | Notes libres |
| Fenêtres de sieste | Calcule la prochaine heure prévue de réveil |
| Couches pour le pédiatre | Compteur quotidien, export CSV |
| Tire-lait | G/D/les deux, volume, durée |
| Courbes de croissance | OMS pour poids, taille, périmètre crânien |
| Fièvre la nuit | Classification 7 niveaux |
| Jumeaux | Deux profils séparés |
| Partage avec pédiatre | CSV/Excel/JSON |

## Comment ça marche

**Où sont mes données ?**
Dans une base SQLite locale. Elles ne quittent jamais l'appareil.

**Faut-il un compte ?**
Non. Vous loggez en moins de dix secondes.

**Vraiment gratuit ?**
Oui — gratuit, pas de pub, pas d'achat intégré, pas d'abonnement. Pour toujours.

**Export ordinateur ?**
CSV, Excel ou JSON.

**Les deux parents ?**
Oui, mais chaque appareil a sa propre base locale (pas de sync cloud).

**Tranches d'âge ?**
Du nouveau-né à 3 ans (36 mois).
