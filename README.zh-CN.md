## MimiLog 是什么？

**MimiLog** 是为 Android 与 iPhone 打造的完全离线、免费的婴儿日记，面向 0 至 3 岁儿童的父母和照护者。记录喂养、小睡、换尿布、吸奶时段、生长测量（体重、身高、头围）于内置 WHO 百分位曲线，并提供详细体温记录。一切都保存在手机的本地 SQLite 数据库——无账号、无云端、无广告、无内购、无订阅，永远不会有。

为凌晨 3 点最不需要付费墙的时刻而生。

## 主要功能

### 喂养
- **母乳计时器**记住从哪侧开始
- **奶瓶**以毫升为单位——母乳/配方奶/混合
- **辅食**——自由文本
- **夜间喂养自动识别**（22:00 至 06:00）

### 睡眠
- **一键小睡与夜间睡眠**
- **从新生儿到学步儿**的自适应作息
- **白天/夜间睡眠总时长与下次清醒窗口**同屏显示

### 尿布
- 尿、便或两者——一键
- **每日计数**，新生儿尿湿尿布过少时温和提醒

### 吸奶
- 左、右或两侧
- 容量、时长、每分钟流速

### 生长与健康
- **体重、身高、头围**于内置 **WHO 百分位曲线**——免费
- **体温日志**含七级发热分类与趋势线
- 洗澡、儿科就诊、自由备注

### 家庭
- **多婴**——双胞胎、兄弟姐妹，数据完全分离
- **共享计时器**重启后仍存活
- **统计**按日/周/月

### 导出
- **CSV、Excel 或 JSON** 直接导入文件管理器

### 隐私
- **100 % 本机**——本地 SQLite 数据库
- **无埋点、无广告 ID、无第三方 SDK**
- **无注册、无邮箱、无密码**
- **深色模式**适合夜间喂养
- **单手操作**——按钮够大

## 使用场景

| 场景 | 应用作用 |
|------|----------|
| 夜间喂养 | 计时器记住侧别并标记为夜间 |
| 托儿所喂瓶 | 一键记录毫升 |
| 第一次辅食 | 自由文本 |
| 睡眠窗口 | 计算下次清醒时间 |
| 给儿科医生看尿布 | 每日计数，导出 CSV |
| 吸奶时段 | 左/右/两侧、容量、时长 |
| 生长曲线 | WHO 体重/身高/头围 |
| 夜间发热 | 七级分类 |
| 双胞胎 | 两个独立档案 |
| 与儿科分享 | 导出 CSV/Excel/JSON |
