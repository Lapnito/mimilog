## MimiLog とは？

**MimiLog** は Android と iPhone のための、完全オフラインで動く無料の育児ダイアリー。生後から 3 歳まで（36 か月）のお子さんを育てる親と保護者向け。授乳、お昼寝、おむつ替え、搾乳セッション、発育測定（体重・身長・頭囲）を WHO パーセンタイル曲線上に、そして体温の詳細記録までまとめて残せます。すべて端末内のローカル SQLite データベースに保存。アカウント不要、クラウド不要、広告なし、アプリ内課金なし、サブスクなし。決して。

午前 3 時、最も必要のないものがペイウォールである瞬間のために作りました。

## 主な機能

### 授乳
- **母乳タイマー**がどちら側から始めたかを記憶
- **哺乳瓶**を ml 単位で（母乳・人工乳・混合）
- **離乳食**は自由記述
- **夜間授乳の自動判定**（22:00–06:00）

### 睡眠
- **昼寝・夜の睡眠**をワンタップ
- **新生児からトドラーまで**適応するスケジュール
- **昼寝・夜の合計と次のウェイクウィンドウ**を 1 画面で

### おむつ
- おしっこ・うんち・両方をワンタップ
- **デイリーカウンター**と新生児の濡れおむつ最低数の優しいリマインド

### 搾乳
- 左・右・両方
- 量、所要時間、毎分の流量

### 発育と健康
- **体重・身長・頭囲**を内蔵 **WHO パーセンタイル曲線**に、無料
- **体温ログ**は 7 段階の発熱分類とトレンドライン付き
- 沐浴、小児科の通院、自由メモ

### 家族
- **複数の赤ちゃん**（双子・きょうだい）— データを厳密に分離
- **共有タイマー**は再起動後も継続
- **統計**は日・週・月

### エクスポート
- **CSV・Excel・JSON** をそのままファイルマネージャーへ

### プライバシー
- **100 % 端末内** — ローカル SQLite
- **アナリティクス／広告 ID／サードパーティ SDK は一切なし**
- **登録・メール・パスワードは一切なし**
- **ダークモード**で夜の授乳に
- **片手で**使える大きなボタン

## 利用シーン

| 場面 | アプリの動作 |
|------|--------------|
| 夜間授乳 | タイマーが側を記憶し夜間として記録 |
| 保育園で哺乳瓶 | ml をワンタップで記録 |
| 初めての離乳食 | 自由記述 |
| お昼寝のリズム | 次のウェイクウィンドウを予測 |
| 小児科向けのおむつ記録 | デイリー、CSV エクスポート |
| 搾乳セッション | 左／右／両方・量・所要時間 |
| 成長曲線 | WHO の体重・身長・頭囲 |
| 夜間の発熱 | 7 段階分類 |
| 双子 | 2 プロファイルを完全分離 |
| 小児科と共有 | CSV／Excel／JSON で送る |
