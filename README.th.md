## MimiLog คืออะไร?

**MimiLog** คือบันทึกทารกที่ทำงานออฟไลน์อย่างสมบูรณ์และฟรีสำหรับ Android และ iPhone ออกแบบสำหรับพ่อแม่และผู้ดูแลเด็กตั้งแต่แรกเกิดถึง 3 ขวบ จดการให้นม การงีบ การเปลี่ยนผ้าอ้อม การปั๊มนม การวัดเจริญเติบโต (น้ำหนัก ส่วนสูง รอบศีรษะ) บนเส้นเปอร์เซ็นไทล์ของ WHO และค่าอุณหภูมิร่างกายโดยละเอียด ทุกอย่างเก็บในฐานข้อมูล SQLite บนเครื่อง ไม่มีบัญชี ไม่มีคลาวด์ ไม่มีโฆษณา ไม่มีการซื้อในแอปและไม่มีการสมัครสมาชิก ไม่มีวัน

สร้างขึ้นเพื่อช่วงเวลาตี 3 ที่สิ่งสุดท้ายที่คุณต้องการคือกำแพงเก็บเงิน

## คุณสมบัติหลัก

### ให้นม
- **ตัวจับเวลาการให้นม** จดจำว่าคุณเริ่มจากด้านไหน
- **ขวดนม** เป็นมิลลิลิตร — นมแม่ นมผง ผสม
- **อาหารแข็ง** — ข้อความอิสระ
- **ตรวจจับการให้นมตอนกลางคืนอัตโนมัติ** ระหว่าง 22:00 ถึง 06:00

### การนอน
- **งีบและการนอนกลางคืน** ด้วยการแตะเดียว
- **กำหนดการที่ปรับได้** ตั้งแต่ทารกแรกเกิดถึงวัยหัดเดิน
- **ผลรวมการนอนกลางวัน/กลางคืนและช่วงเวลาตื่นถัดไป** ในหน้าจอเดียว

### ผ้าอ้อม
- ฉี่ อึ หรือทั้งสอง — แตะเดียว
- **ตัวนับรายวัน** พร้อมการเตือนนุ่มนวลหากผ้าอ้อมเปียกของทารกแรกเกิดน้อย

### ปั๊มนม
- ซ้าย ขวา หรือทั้งสองข้าง
- ปริมาตร ระยะเวลา อัตราการไหลต่อนาที

### การเจริญเติบโตและสุขภาพ
- **น้ำหนัก ส่วนสูง รอบศีรษะ** บน **เส้นเปอร์เซ็นไทล์ WHO** ฟรี
- **บันทึกอุณหภูมิ** พร้อมการจำแนกไข้ 7 ระดับและเส้นแนวโน้ม
- การอาบน้ำ การไปกุมารแพทย์ บันทึกอิสระ

### ครอบครัว
- **หลายทารก** — แฝด พี่น้อง ข้อมูลแยกกัน
- **ตัวจับเวลาที่ใช้ร่วมกัน** อยู่รอดหลังรีบูต
- **สถิติ** รายวัน รายสัปดาห์ รายเดือน

### ส่งออก
- **CSV, Excel หรือ JSON** ตรงไปยังตัวจัดการไฟล์

### ความเป็นส่วนตัว
- **100 % บนอุปกรณ์** — ฐานข้อมูล SQLite ในเครื่อง
- **ไม่มี analytics, ID โฆษณา, SDK บุคคลที่สาม**
- **ไม่มีการสมัคร อีเมล หรือรหัสผ่าน**
- **โหมดมืด** สำหรับการให้นมตอนกลางคืน
- **มือเดียว** — ปุ่มขนาดใหญ่

## กรณีใช้งาน

| สถานการณ์ | สิ่งที่ MimiLog ทำ |
|-----------|---------------------|
| การให้นมตอนกลางคืน | ตัวจับเวลาจดจำด้านและทำเครื่องหมายเป็นกลางคืน |
| ขวดนมที่สถานรับเลี้ยงเด็ก | ml ในการแตะเดียว |
| อาหารแข็งครั้งแรก | ข้อความอิสระ |
| ช่วงเวลาการนอน | คาดการณ์เวลาตื่นถัดไป |
| ผ้าอ้อมสำหรับกุมารแพทย์ | ตัวนับรายวัน, ส่งออก CSV |
| เซสชันปั๊มนม | ซ/ข/ทั้งสอง, ปริมาตร, ระยะเวลา |
| เส้นการเจริญเติบโต | WHO น้ำหนัก ส่วนสูง รอบศีรษะ |
| ไข้กลางดึก | การจำแนก 7 ระดับ |
| แฝด | สองโปรไฟล์แยก |
| แชร์กับกุมารแพทย์ | CSV/Excel/JSON |

## ทำงานอย่างไร

**ข้อมูลของฉันอยู่ที่ไหน?** ในฐานข้อมูล SQLite บนเครื่อง ไม่เคยออกจากอุปกรณ์ **ต้องสมัครสมาชิกไหม?** ไม่ **ฟรีจริงไหม?** ใช่ — ไม่มีโฆษณา การซื้อ การสมัครสมาชิก ตลอดไป
