## ما هو MimiLog؟

**MimiLog** هو يوميات رضيع مجانية تعمل دون اتصال بالكامل لـ Android وiPhone، مصممة للآباء والأمهات ومقدمي الرعاية للأطفال من الولادة حتى سن الثالثة. تسجل الرضعات، القيلولات، تغييرات الحفاضات، جلسات الشفط، قياسات النمو (الوزن، الطول، محيط الرأس) على منحنيات منظمة الصحة العالمية، وقراءات حرارة الجسم التفصيلية. كل شيء يُحفظ في قاعدة بيانات SQLite محلية على الهاتف — لا حساب، لا سحابة، لا إعلانات، لا مشتريات داخل التطبيق ولا اشتراك. أبدًا.

صُنع لتلك اللحظات في الثالثة فجرًا حين آخر ما تحتاجه هو شاشة دفع.

## أهم الميزات

### الرضاعة
- **مؤقت رضاعة طبيعية** يتذكر من أي ثدي بدأت
- **زجاجة** بالملليلتر — حليب أم، حليب صناعي، مختلط
- **الطعام الصلب** — نص حر
- **اكتشاف تلقائي للرضعات الليلية** بين 22:00 و06:00

### النوم
- **القيلولة والنوم الليلي** بنقرة واحدة
- **جدول قابل للتكيف** من حديث الولادة إلى الطفل
- **نوم النهار/الليل ونافذة اليقظة التالية** على شاشة واحدة

### الحفاضة
- بول، براز أو كلاهما — نقرة واحدة
- **عداد يومي** مع تذكير لطيف إذا انخفضت الحفاضات المبللة لحديث الولادة

### الشفط
- يسار، يمين أو كلاهما
- الحجم، المدة، التدفق في الدقيقة

### النمو والصحة
- **الوزن والطول ومحيط الرأس** على **منحنيات منظمة الصحة العالمية** المدمجة، مجانًا
- **سجل الحرارة** بتصنيف الحمى من سبعة مستويات وخط للاتجاه
- الاستحمام، زيارات الطبيب، ملاحظات حرة

### العائلة
- **عدة رضع** — توأم، إخوة، بيانات منفصلة
- **مؤقت مشترك** يصمد أمام إعادة التشغيل
- **إحصائيات** يومية وأسبوعية وشهرية

### التصدير
- **CSV أو Excel أو JSON** مباشرةً إلى مدير الملفات

### الخصوصية
- **100 % على الجهاز** — قاعدة بيانات SQLite محلية
- **بدون تحليلات، بدون معرفات إعلانية، بدون SDK لطرف ثالث**
- **بدون تسجيل، بريد، أو كلمة سر**
- **الوضع الداكن** للرضعات الليلية
- **بيد واحدة** — أزرار كبيرة

## حالات الاستخدام

| الحالة | ماذا يفعل MimiLog |
|--------|--------------------|
| رضعة ليلية | يتذكر الجانب ويعلّمها كرضعة ليلية |
| زجاجة في الحضانة | مل بنقرة واحدة |
| الأطعمة الأولى | نص حر |
| نوافذ النوم | يتنبأ بموعد الاستيقاظ التالي |
| حفاضات للطبيب | عداد يومي، تصدير CSV |
| جلسة شفط | يسار/يمين/كلاهما، حجم، مدة |
| منحنيات النمو | WHO للوزن والطول ومحيط الرأس |
| حمى ليلية | تصنيف من 7 مستويات |
| توأم | ملفان منفصلان |
| المشاركة مع الطبيب | CSV/Excel/JSON |

## كيف يعمل

**أين تُحفظ بياناتي؟**
في قاعدة بيانات SQLite محلية. لا تغادر جهازك.

**هل أحتاج حسابًا؟**
لا.

**مجاني فعلًا؟**
نعم — بدون إعلانات، مشتريات أو اشتراك. للأبد.

**التصدير إلى الكمبيوتر؟**
CSV أو Excel أو JSON.

**هل يمكن للوالدين استخدامه؟**
نعم، لكن لكل جهاز قاعدة بيانات محلية خاصة (لا مزامنة سحابية).

**من أي عمر إلى أي عمر؟**
من حديث الولادة إلى 3 سنوات (36 شهرًا).
