# MimiLog: Baby & Infant Log

Buku harian bayi gratis dan offline untuk usia 0–3 tahun: menyusu, tidur, popok, memompa ASI, pertumbuhan, dan suhu. Tanpa akun atau iklan.

- Google Play: https://play.google.com/store/apps/details?id=com.mimiapp.mimilog
- App Store: https://apps.apple.com/us/app/mimilog-baby-infant-log/id6762612529
- Package: `com.mimiapp.mimilog`
- Developer: lapnito.cz s.r.o.
