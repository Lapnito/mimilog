## MimiLog란?

**MimiLog**은 Android와 iPhone을 위한 완전 오프라인 무료 아기 다이어리입니다. 출생부터 3세까지 자녀를 둔 부모와 양육자를 위해 만들어졌습니다. 수유, 낮잠, 기저귀 갈이, 유축 세션, 성장 측정(체중·키·머리둘레)을 WHO 백분위 곡선 위에, 그리고 체온의 상세 기록을 남깁니다. 모든 것은 휴대폰의 로컬 SQLite 데이터베이스에 저장됩니다 — 계정 없음, 클라우드 없음, 광고 없음, 인앱 결제 없음, 구독 없음. 영원히.

새벽 3시, 페이월이 가장 필요 없는 그 순간을 위해 만들었습니다.

## 주요 기능

### 수유
- **모유 수유 타이머** — 어느 쪽에서 시작했는지 기억
- **젖병** ml 단위 — 모유, 분유, 혼합
- **이유식** 자유 기록
- **야간 수유 자동 인식** (22:00–06:00)

### 수면
- **낮잠과 야간 수면** 한 번의 탭
- **신생아부터 토들러까지** 적응형 일정
- **주간/야간 수면 합계와 다음 깨어남 창** 한 화면에

### 기저귀
- 소변/대변/둘 다 — 한 번의 탭
- **일일 카운터**와 신생아의 젖은 기저귀가 적을 때 부드러운 알림

### 유축
- 좌·우·양쪽
- 양, 시간, 분당 흐름

### 성장과 건강
- **체중·키·머리둘레**를 내장 **WHO 백분위 곡선** 위에, 무료
- **체온 로그** — 7단계 발열 분류 + 추세선
- 목욕, 소아과 방문, 자유 메모

### 가족
- **여러 아이** — 쌍둥이, 형제자매, 데이터 분리
- **공유 타이머** — 재부팅에도 살아남음
- **통계** — 일/주/월

### 내보내기
- **CSV, Excel 또는 JSON** 바로 파일 매니저로

### 개인정보 보호
- **100 % 기기 내** — 로컬 SQLite 데이터베이스
- **분석, 광고 ID, 외부 SDK 없음**
- **가입, 이메일, 비밀번호 없음**
- **다크 모드** 야간 수유용
- **한 손**으로 — 큰 버튼

## 사용 시나리오

| 상황 | MimiLog가 하는 일 |
|------|--------------------|
| 야간 수유 | 타이머가 쪽을 기억하고 야간으로 표시 |
| 어린이집의 젖병 | 한 번의 탭으로 ml 기록 |
| 첫 이유식 | 자유 텍스트 |
| 수면 창 | 다음 깨어남 시각 예측 |
| 소아과용 기저귀 | 일일 카운터, CSV 내보내기 |
| 유축 세션 | 좌/우/양쪽, 양, 시간 |
| 성장 곡선 | 체중·키·머리둘레의 WHO |
| 한밤중의 발열 | 7단계 분류 |
| 쌍둥이 | 두 개의 분리된 프로필 |
| 소아과와 공유 | CSV/Excel/JSON |

## 작동 방식

**내 데이터는 어디에?** 로컬 SQLite. 기기를 떠나지 않습니다. **계정 필요?** 아니요. 10초 안에 기록 시작. **정말 무료?** 네 — 광고·결제·구독 없음, 영원히.
